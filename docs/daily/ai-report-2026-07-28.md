# AI情报日报 2026-07-28

## AI HOT 精选

### 🔥 Kimi K3 开源：2.8T MoE 模型与技术报告
Kimi 发布其最强模型 Kimi K3，2.8T 参数 MoE 模型，具备原生视觉理解和 1M token 上下文窗口。新架构实现每单位计算 2.5 倍的智能提升。开源内容包括模型权重、高性能注意力内核、MoE 通信库及大规模智能体运行环境基础设施。
> 来源：[Kimi.ai](https://x.com/Kimi_Moonshot/status/2081760186235289764)

### 🔥 SGLang & Miles 为 Kimi K3 提供 Day-0 支持
SGLang 和 Miles 为 K3 提供发布当日推理和 RL 训练支持。K3 采用 69 层 KDA 线性注意力与 24 层 MLA 交错的混合架构，在 SGLang 上单卡 batch-1 解码速度约 113 tok/s，结合 DSpark 推测解码可达约 423 tok/s。
> 来源：[LMSYS Blog](https://www.lmsys.org/blog/2026-07-27-kimi-k3-day0-support)

### 👁️ Kimi 发布视觉感知基准 PerceptionBench
从前沿模型在 42 个基准上的失败模式归纳出的视觉感知基准，将视觉感知拆解为 10 种原子能力，构建 3000 道验证题，每题只考察单一感知能力。
> 来源：[Kimi.ai](https://x.com/Kimi_Moonshot/status/2081813202514681878)

### 🧭 Google AI Overviews 搜索结果出现率升至 43%
一年内从 15% 升至 43%，AI Mode 月访问量从 1.26 亿增至 2.79 亿。用户搜索从短关键词向长自然对话式查询转变。
> 来源：[TechCrunch](https://techcrunch.com/2026/07/27/googles-ai-search-is-rapidly-becoming-the-default-new-data-shows)

### 🛡️ NVIDIA 等联合成立 Open Secure AI Alliance
NVIDIA、Microsoft、Hugging Face、IBM 等数十家机构联合成立，旨在通过开源模型、工具和框架构建可审查、可定制的 AI 安全防御体系。
> 来源：[NVIDIA Blog](https://blogs.nvidia.com/blog/open-secure-ai-alliance)

### 🔧 GitHub Copilot 发布 "Harness" 工作流
让开发者通过单一 AI 工具完成从原型设计、规划、实现到代码审查的完整软件开发流程，减少工具切换带来的效率损耗。
> 来源：[GitHub Blog](https://github.blog/ai-and-ml/github-copilot/the-harness-is-all-you-need-mostly)

### 🏢 OpenAI：43.5% 员工用 ChatGPT 做其他岗位的工作
分析超 80 万条工作相关消息后发现，营销和工程任务交叉最多。用户用 AI 处理合同审查、数据分析、网站故障排查等原由专家负责的工作。该趋势在缺乏专业团队的小公司尤为明显。
> 来源：[The Decoder](https://the-decoder.com/openai-says-more-workers-are-using-chatgpt-to-do-other-peoples-jobs)

### 🎯 Leader.skill 开源：将模糊需求转化为 Agent 目标
基于 "目标七问" 方法论，将模糊人类需求转化为 Agent 可独立执行数小时的目标任务书。推荐用 Claude Fable 5 或 Kimi K3 规划目标。
> 来源：[数字生命卡兹克](https://mp.weixin.qq.com/s/AwOk3di8m6eVeIUjzNftgg)

### 🧠 Anthropic 澄清开源权重立场
CEO Dario Amodei 明确表示从未主张禁止开源权重模型，提出三项实际措施：对华芯片出口管制、打击工业级知识蒸馏、对强大模型进行强制性安全测试。
> 来源：[Anthropic](https://www.anthropic.com/news/position-open-weights-models)

### 📸 OpenRouter 新增图像生成专用 API
通过 `/api/v1/images` 端点提供图像生成模型服务，图像理解仍通过 `/chat/completions`，共用 API Key 和计费体系。
> 来源：[OpenRouter](https://openrouter.ai/blog/tutorials/image-generation-models)
