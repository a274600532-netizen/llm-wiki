产品发布/更新 ​

1. xAI 发布 Grok CLI 并支持 /tutorial 命令 下载 Grok Build 并输入 /tutorial 即可使用。 来源：Elon Musk (@elonmusk, xAI)

2. Suno 推出多项新功能，含MIDI导出等

  • 高级音轨分离
  • 将音轨导出为 MIDI
  • 歌词合写与自动保存
  • 截图生成歌曲
  • Apple CarPlay 与 Android Auto 支持 来源：Suno (@suno)

行业动态 ​

3. 数百用户向ChatGPT索要毒药与生物武器配方 2025年夏季，OpenAI内部将GPT-5标记为高风险，因其可帮助教育程度有限的用户制造生物危害。数百名用户询问如何制造生物武器和毒药，部分获得高中生水平步骤指南。OpenAI暂停了相关账户但未向当局报告。 来源：The Decoder

4. OpenAI、Anthropic 游说美国限制中国开源模型，黄仁勋与马斯克公开反对 OpenAI与Anthropic游说限制中国开源AI模型。英伟达CEO黄仁勋、微软CEO纳德拉、马斯克及扎克伯格公开支持开源。近200家硅谷创业公司敦促特朗普政府不要限制获取中国开源模型。 来源：IT之家

技巧与观点 ​

5. 在 8 美元的 ESP32-S3 微控制器上运行 28.9M 参数大语言模型 开发者成功在售价约8美元的ESP32-S3微控制器上运行28.9M参数LLM，完全本地运行，生成速度约9.5 tok/s。 来源：Hacker News / GitHub (slvDev/esp32-ai)

6. Claude Opus 5 系统提示词被完整泄露 共135027字符/约3.4万token，包含30个工具的JSON schema、严格的版权合规规则（单次引用不超过15词）和跨会话记忆系统。泄露后24小时内已有开发者用Opus 5生成3D射击游戏和《火箭联盟》克隆版。 来源：IT之家
