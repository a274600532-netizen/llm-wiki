产品发布/更新

  1. Cursor 推出 Origin 代码托管服务，作为 GitHub 的替代方案 — Cursor 向所有付费计划用户开放 Origin 代码托管早期测试版，提供仓库、拉取请求、代码浏览及 GitHub 双向同步功能，仓库以 cursor.com/codebase/ 为前缀。
  2. OpenRouter 推出 Activity 仪表盘与 Analytics API — 可按智能体、模型、请求维度追踪 AI 使用成本，查看支出、token 量、缓存命中率等指标，并支持下钻至单条请求日志。
  3. OpenRouter 图像生成 API：代码优先接入教程 — 通过统一请求格式和单一密钥即可调用多家提供商的图像模型，POST /api/v1/images 返回 base64 图像数据。
  4. Claude Code v2.1.234 发布 — 新增 CLAUDE_CODE_PROJECT_DIR_NAME 环境变量、selection:clear 键绑定及 GitLab MR 徽章，修复多项安全与稳定性问题。

  3. OpenAI 资助 14 个独立项目共 100 万美元 — 另配最高 100 万美元 API 额度，推动 AI 进步下的经济机遇与社会韧性研究。

论文研究

  1. PhotoScan：用智能手机照片估算胰岛素抵抗 — Google Research 推出深度学习框架，从 2D 照片直接估算三维身体成分，精度接近临床 DXA 扫描。

技巧与观点

  1. OpenAI 如何用前沿智能加固自身防御："The Defender's Window" — 事件后反思低估了模型真实网络攻击能力，通过四大支柱强化安全：Codex 验证代码漏洞、智能体优先分流告警、持续枚举攻击路径、仅向可信防御者开放网络能力。
  2. 当模型持续学习：测试时训练（TTT）如何改变 AI 的记忆与成本 — TTT 让模型使用中持续更新权重，内存需求从随上下文线性增长变为恒定；斯坦福研究显示推理速度最高提升 2.7 倍，4B 模型可达 128k 上下文性能。

另有关注点：Hugging Face GPU 分配器提升集群利用率最高 33 个百分点；SGLang Breakable CUDA Graph 成 prefill 默认方案；Google 开源 ADK 零信任智能体示例；404 Media 追踪发现亚马逊批量购书扫描用于 AI 训练后销毁。
