AI情报日报 2026-08-15 ​

AI HOT 精选 ​

模型发布/更新 ​

  1. GLM-5.3 发布：编程能力开源第一，并涌现网络安全能力 智谱发布 GLM-5.3，基于与 GLM-5.2 相同基座，通过极致的后训练 Scaling 提升智能上界。编程能力较前代提升 50%，在 Terminal Bench 3.0 等公开基准取得开源第一，接近 Claude Fable 5；白盒代码审查等安全任务表现持平 Mythos 5，CyberGym 测试得分 84.5%。权重两周后开源，即日上线 ZCode、AutoClaw 等工具。 来源：公众号：智谱（GLM）

  2. dots3-note Preview 开源：280B 参数轻量模型，主打长程智能体与多模态推理 小红书技术开源 dots3 系列最轻量模型，总参数 280B、激活参数 16B，支持 512K 上下文及文本、视觉、语音多模态理解，针对复杂推理和长程 Agent 任务优化。 来源：公众号：小红书技术（dots.llm）

  3. DeepSeek V4 Pro 登陆硅基流动，1M 上下文 DeepSeek-V4-Pro-0813 上线 SiliconFlow，Day-0 支持，1M 上下文窗口，低/高/最大三档推理强度，侧重编码、工具调用与智能体工作流，保持 MIT 开源。定价：输入 $1.32/M、输出 $3.96/M、缓存命中 $0.44/M。 来源：X：硅基流动 SiliconFlow

  4. Gemini 3.7 Flash 全面上线 Pro 与 Ultra 用户 Gemini 3.7 Flash 向 Gemini 聊天 Pro/Ultra 用户开放，提升多步骤任务推理与准确性（如整合数十个文件与邮件为一份主文档）；Gemini Spark 也运行于 3.7 Flash，改进对 Google Workspace 的工具调用。 来源：X：Gemini (@GeminiApp)

产品发布/更新 ​

  1. Claude Code v2.1.233 发布：新增 GitLab MR 支持与内存 cgroup 限制 为 --worktree 标志和 agents 视图新增 GitLab 合并请求 URL 支持，新增可选 forward_user_identity 网关设置，可按用户归因支出。 来源：Claude Code GitHub Releases

行业动态 ​

  1. Cursor 正式被 SpaceX 收购 Cursor 完成自 4 月启动的收购流程，正式并入 SpaceX。合并后 Cursor 将获得全球最大 GPU 集群，以更低成本构建更强模型；本周三发布的 Grok 4.6 是双方合作成果的早期体现。 来源：Cursor Blog

  2. OpenAI 与 Anthropic 打响价格战，中国 AI 厂商崛起施压 API 价格战使成本弹性成为现实，原先因账单压力转向中国厂商的用户，可能在 OpenAI/Anthropic 降价后重新比较能力与价格。 来源：Ars Technica

  3. Claude 文本水印机制如何运作 未来 Claude 生成文本将含水印（基于 Google DeepMind SynthID-Text 技术），用于判断文本是否由 Claude 撰写，为遵守欧盟《AI 法案》而实施。对输出质量无实际影响、不增加 token 或成本，读者无法区分。 来源：Anthropic Newsroom

技巧与观点 ​

  1. 2026 夏季开源模型生态观察：中国前沿模型规模领先，AMD 与 NVIDIA 主导发布量 Hugging Face 公开模型仓库从 243 万增至 296 万，但 85.6% 模型下载量不足 200 次，1.5% 仓库占据 99.2% 下载量。中国实验室月度最大开源模型参数规模 754B~2.78 万亿，美国实验室七个月中五个月低于 130B。AMD 与 NVIDIA 各发布超 200 个新模型仓库。 来源：Hugging Face Blog

  2. 谁真的需要 SOTA 模型？OpenRouter 数据显示 84% token 来自非前沿模型 用户最常用的六款模型性能约为前沿模型的 77%，成本仅为 Claude Fable 5 的 2.5%（混合价约 $0.50 vs $20/百万 token）。最佳开源模型性能已从一年前的 48% 提升至前沿模型的 80%，企业正转向更小、微调或开源模型优化性价比。 来源：Tomer Tunguz 博客（VC 分析）
