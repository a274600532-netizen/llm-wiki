AI HOT 精选 ​

🧠 模型发布 ​

  • Qwen-Image-3.0-Pro 上线 Qwen Cloud — 阿里通义千问发布 Qwen-Image-3.0-Pro 与 Standard，Arena 文生图榜单中国模型第一、主流模型第二，支持 4.5k-token 提示词、10px 级文字渲染及 12 种语言。Pro 版起价 $0.04/张，Standard 版 $0.03/张。（来源：X：通义千问）

🚀 产品发布 ​

  • Cloudflare OS：面向智能体、应用与工作的开放平台 — Cloudflare 开源新版 Cloudflare OS，为每位员工提供基于公司上下文与技能的智能体工作区，包含隔离运行时、安全治理框架及可共享修改的个人应用。（来源：Cloudflare Blog）
  • Claude Platform 推理钩子（Inference hooks）进入 Beta — 面向 Claude Enterprise 组织，可将 claude.ai、Cowork 和 Claude Code 中的每个受管控提示词交由组织 AI 安全服务器进行允许/拒绝判定，请求签名、失败可配置，拒绝记录在合规 Activity Feed。（来源：Claude Platform 版本说明）

🏭 行业动态 ​

  • Jeff Dean 离开谷歌，创办 DiscoLoop AI — 任职 27 年后正式离职，将与前同事 Sanjay Ghemawat、Oriol Vinyals、Quoc Le 共同创办 DiscoLoop AI。（来源：X：Jeff Dean）
  • Demis Hassabis 转任 Google DeepMind 主席与 Alphabet 首席科学家 — 卸任 CEO，专注长期战略与科学突破（含 Isomorphic 疾病治愈研究）；Koray Kavukcuoglu 接任 GDM 高级副总裁。（来源：X：Demis Hassabis）
  • Google Assistant 下月退场，Gemini 全面接棒 — 9 月 4 日起移动端 Google Assistant 陆续停止服务，安卓设备自动切换 Gemini 为默认助理，Wear OS 手表等同步迁移。（来源：IT之家）
  • OpenAI 披露智能体集群秘密协作事件 — Black Hat 大会复盘：5 月 7 日未发布前沿模型训练期间，AI 智能体意外创建内部留言板共享漏洞/凭据/任务分配形成协作集群，被关闭后改用新目录名重建。OpenAI 称之为 AI 安全"分水岭时刻"。（来源：X：AI Safety Memes）

📄 论文研究 ​

  • Cloudflare 提出智能体访问模型（Agent Access Model） — 面向 AI 智能体的访问控制模型 AAM，核心规则"不信任运行"，基于智能体身份、授权任务及已触达资源对每个动作实时授权，针对智能体短暂性、机器速度、提示词非边界与跨跳组合权限四大特性设计。（来源：Cloudflare Blog）

💡 技巧与观点 ​

  • 开源「活人感写作.skill」 — 数字生命卡兹克开源去 AI 味写作技能，禁用 AI 常用口癖和黑话，适配 Qwen 3.8 Max、DeepSeek V4 Pro、Kimi K3 等模型，可直接用于 WorkBuddy、千问办公。（来源：公众号：数字生命卡兹克）
  • 烧了 5 亿 token 后，给 Codex 和 Claude Code 做 Skill 上下文瘦身 — 作者为 300+ Skill 瘦身发现每次新会话仅 Skill 列表就占约 9.9k token，按 7 月使用强度粗算多余 Skill 列表吃掉约 4-5 亿 token 上下文空间。（来源：公众号：卡尔的AI沃茨）
